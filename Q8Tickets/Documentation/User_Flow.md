# User Flow

This document describes the typical user journey through the **Q8Tickets** application.

## Customer Flow

### 1. Access the Application

The user opens the Q8Tickets web application.

↓

### 2. Authentication

The user either:

* Signs in using an existing account.
* Creates a new account if they are a first-time user.

↓

### 3. Browse Available Matches

The user views a list of upcoming football matches, including:

* Match date and time
* Participating teams
* Stadium information

↓

### 4. Select a Match

The user chooses a match and proceeds to the booking page.

↓

### 5. Book Tickets

The user selects:

* Number of tickets
* Stadium section
* Row number
* Seat number
* Payment method

↓

### 6. Confirm Booking

The system validates the booking information, stores the reservation, and generates a booking record.

↓

### 7. View Booking Summary

The user reviews:

* Booking details
* Total price
* Payment method
* Barcode for entry

↓

### 8. Share Booking (Optional)

The user can share booking information through supported social media platforms.

↓

### 9. Modify Booking (Optional)

Before the match, the user may update:

* Ticket quantity
* Seating section

↓

### 10. Submit Feedback

After attending the match, the user can submit:

* Rating
* Comment

---

# Administrator Flow

### 1. Sign In

The administrator logs into the system.

↓

### 2. Manage System Data

The administrator can:

* Manage customers
* Manage stadiums
* Manage football matches
* Manage seating sections
* Manage bookings
* Manage payments

↓

### 3. Monitor Statistics

The administrator can access dashboards displaying:

* Booking statistics
* Player performance statistics
* Match statistics
* User feedback

↓

### 4. Maintain the Database

The administrator updates records and ensures the application data remains accurate and up to date.
