# Database Design

The Q8Tickets application is built on a relational Oracle Database designed to manage users, matches, bookings, payments, stadiums, and feedback.

## Relational Schema

### Main Tables

- Customer
- Match
- Stadium
- Section
- Booking
- Payment
- Ticket
- Feedback
- Social Sharing

The database is normalized to reduce redundancy and maintain data integrity through primary keys, foreign keys, and relationships between entities.
